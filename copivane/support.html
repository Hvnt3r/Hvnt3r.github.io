Copivane

Support

Copivane runs in the menu bar. Press Shift–Command–V to open it, type to search, use the arrow keys to select a card, and press Return to restore it.

Capture is not starting

Turn Capture On in Copivane and allow clipboard access when macOS asks. If access was denied, open System Settings → Privacy & Security → Pasteboard and allow Copivane.

Direct paste is not working

Direct paste is optional and off by default. Enable it in Settings → General and allow Copivane in System Settings → Privacy & Security → Accessibility. Without permission, Copivane still restores the clipboard so you can press Command–V manually.

Restore Copivane Pro

Open Settings → Copivane Pro and choose Restore Purchase. Use the same Apple Account that originally purchased the upgrade.

Copivane

支持

Copivane 在菜单栏运行。按下 ⇧⌘V 打开面板，输入文字搜索，使用方向键选择卡片，按回车恢复内容。

无法开始记录

请在 Copivane 中打开“记录”，并在 macOS 询问时允许剪贴板访问。如果之前拒绝过，请前往“系统设置 → 隐私与安全性 → 粘贴板”，允许 Copivane。

直接粘贴不起作用

直接粘贴默认关闭。请在“设置 → 通用”中启用，并在“系统设置 → 隐私与安全性 → 辅助功能”中允许 Copivane。没有权限时，Copivane 仍会恢复剪贴板，你可以手动按下 ⌘V。
